--------------------------------------------------------------------------------
2. SUSPECTED ROOT CAUSE
--------------------------------------------------------------------------------
(a) VRAM exhaustion on the render GPUs.
    - scripts/awr_libero_babel.sh sets XLA_PYTHON_CLIENT_MEM_FRACTION=0.95, so
      JAX preallocates 95% of EVERY visible GPU.
    - src/envs/libero.py:106 sets render_gpu_device_id = rank % num_devices, i.e.
      offscreen renderers are spread across ALL GPUs (env_num=8 + eval_env_num=8
      = up to 16 EGL contexts) -- the SAME GPUs JAX filled to 95%.
    - MuJoCo/robosuite then cannot allocate the offscreen framebuffer -> 0x8cdd.
    - Intermittent: only bites when collection runs (step 10000), not at startup.

(b) Possible EGL device-id mismatch under Slurm (secondary hypothesis).
    - Shell sets MUJOCO_EGL_DEVICE_ID = first CUDA_VISIBLE_DEVICES index; robosuite
      instead uses render_gpu_device_id (rank % num_devices). Under Slurm's GPU
      remapping the EGL device index need not match the CUDA index.

5. PROPOSED FIXES (validate these on the debug node)
--------------------------------------------------------------------------------
FIX 1 (PRIORITY - prevents the node drain): make env teardown bounded so a wedged
       worker can NEVER hang the job. Replace src/envs/venv.py close_env()
       (L495-504) with bounded poll/join + SIGTERM->SIGKILL escalation:

    def close_env(self) -> None:
        try:
            self.parent_remote.send(["close", None])
            if self.parent_remote.poll(5):
                self.parent_remote.recv()
        except (BrokenPipeError, EOFError, AttributeError, OSError):
            pass
        try:
            self.process.join(timeout=5)
            if self.process.is_alive():
                self.process.terminate()      # SIGTERM
                self.process.join(timeout=5)
            if self.process.is_alive():
                self.process.kill()           # SIGKILL - releases GPU/EGL context
                self.process.join(timeout=5)
        except (AttributeError, OSError):
            pass

    Validate: after the crash, env.close() must return within ~15s/worker and
    leave no stray GPU processes (check nvidia-smi / `ps`).

FIX 2 (prevents the crash): give EGL framebuffers VRAM headroom on the shared
       GPUs. In scripts/awr_libero_babel.sh:
           export XLA_PYTHON_CLIENT_MEM_FRACTION=0.75   # was 0.95 (tune lower if needed)

FIX 3 (Slurm safety net): add to #SBATCH header so Slurm signals before hard-kill:
           #SBATCH --signal=B:TERM@120
