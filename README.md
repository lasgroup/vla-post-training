# MolmoSpaces Setup

If you want to use MolmoSpaces in this repo on CSCS, there is no need to run the Molmo install script. The shared assets and cache are already set up.

See [docs/molmo_cscs_edf_setup.md](docs/molmo_cscs_edf_setup.md) for the EDF `.toml` setup and the shared `MLSPACES_ASSETS_DIR` / `MLSPACES_CACHE_DIR` values to use.
